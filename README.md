# WSDL (wsdl)
WSDL (Web Services Description Language) is a W3C standard XML format for describing web service interfaces. It defines services as collections of network endpoints (ports) that exchange messages, specifying the abstract operations, message formats, and protocol bindings needed to interact with a web service.

**URL:** [Visit APIs.json URL](https://www.w3.org/TR/wsdl20/)
